# Bounded replay argument and detection policy

This is a source argument plus executable controls for the pinned Yjs13.6.31 seam, not a formal proof for arbitrary Yjs documents or a replacement for the canonical verification contract.

Let P be an accepted private runtime history and D its sole next accepted native text delta. The guarded fresh fork F(P) is detached, normalized and has complete copied stacks/redone links. Its command produces Q. Once Q has passed the existing full canonical adoption comparison, the exact earlier transferred P may be retired, together with a private detached D and an identity reference to Q. Next preparation may reuse P only if Q is still the accepted basis. Replaying D into that untouched P yields the same integrated identities/content/deletions as Q; full stack and selection-metadata copying restores the non-wire history. The next command remains subject to all old writer/revision/slice and canonical checks.

Induction preconditions are enforced by distinct owners. Workspace acceptance only creates a spare for an actual text-only transition on the conservative normalized domain; the queue registers only an earlier transferred exact state, after full verified adoption. Reacquisition consumes that registration. No-op/discard do not retire a new basis; retained retry keeps the same preparation. Remote invalidates before applying or notifying; structural/metadata/undo/redo/surrogate preparation disposes the spare and takes a fresh fork. Only two private histories are retained. New head writer is set after replay. The spare delta is copied before the prepared update is wiped and never exposed through workspace APIs. Scope acquisition precedes replay; failure/cancel uses the existing lease-bound disposal. Reset/consume/close erase its bytes.

Normalization: pending structs/deletes, gc:true, destroyed docs, surrogates (including pairs), unsupported content, binary/exotic/cyclic/sparse/extended/accessor/nonenumerable values are excluded. The guard visits deleted content too. For accepted dense plain ContentAny data and BMP-only keys/strings, the pinned native V1 and private V2 fork preserve the same scalar trees; no cross-field surrogate normalization occurs. Existing text command operations insert/delete strings; no permitted text command creates an embedded object, rich-text format, nested Y type or redone link. Actual changed-type inspection prevents membership/metadata/structural effects from propagating the eligibility fact. Unknown foreign changes invalidate before preparation. Extending this domain or adding mutation paths requires a fresh argument.

History: gc:false retains deleted data independently of keep bits. Text replay does not run UndoManager tracking under its untracked catch-up origin. Complete detached copies of undo and redo items, insertion/deletion ranges, lastChange and per-owner opaque selection metadata replace the target's old stacks. UndoManager transient undoing/redoing/current-item fields are at rest outside synchronous commands. Old Item.redone links are already in P. Pinned Item.splitItem preserves redone offsets and mergeWith refuses to merge items with redone links. Text operations add no redone links. After undo/redo/structural mutation the fresh fork still copies links by ID. Generated tests compare the per-clock redone relation as well as complete stacks and eventual undo/redo results; encoded document equality alone would not cover them.

The removed check was a new prototype defense against drift in a retired basis, not an existing admission check. Preserve transactional drift refusal with a lightweight beforeTransaction observer attached only while idle. Any intervening transaction (even no-op) invalidates reuse; consume checks after reacquiring ownership and detaches the observer before authorized replay. Reset/failed consume/close detach it too. Raw writes to private Yjs fields, mutable ContentAny payloads, history stacks, or the private delta bypass this observer. The old added comparison could catch some raw document-content drift but did not check stacks/redone either. Those mutations violate the sole-mutator contract; they are not safe because a later verifier exists. Explicit controlled experiments retain this boundary rather than describing detection as equivalent. The internal seam is trusted composition, not a sandbox or generic public replay API.

Every preexisting complete canonical comparison remains byte-identical. It still detects mismatched promoted candidates, but can do so after durable append; no claim is made that such a failure restores a wrong preparation basis. Correct replay comes from the ownership/normalization invariant and tests, not from moving the new check to a later point. If any in-contract counterexample survives, candidate timing and selection must stop.
