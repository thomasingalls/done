## Sustained API mechanism and remaining writer guardrail

Three additional corrected-API observations read the same 1,024 positions as 128 eight-entry pages in 3.216–3.974 s, with zero 429s and every returned replay/peer/live-write proof independently verified. These follow-up runs are not a fresh alternating API comparison; do not pool them into the preceding paired estimate. They demonstrate that denser pages remove the observed admission ceiling without raising numeric rates.

A remaining cost must not be hidden: the short continuous loop's first few same-publisher writes take about 0.8 s, whereas later writes during the long limit-one run often take milliseconds. Unequal exposure windows make full-window p95s incomparable as a simple capacity claim. The separate diagnostic clone shows same-authority count-growth commit races clearing the entire prefix memo and repeated full 1,024-row censuses around writes. Preserve that guardrail discrepancy. A further bounded append-evidence reuse phase is required before accepting this candidate as the final series; no current-request guard, external-change or corruption check may be removed to repair it.
