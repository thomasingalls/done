# Scope and measurement limits

The fixed plan uses the exact phase09 temporary B32/128 source, exact patch02 client and exact original encrypted browser fixtures. Production defaults and all old tests remain untouched. Only the disposable test harness/control DOM changes. No CPU profiler or crypto/IDB prototype wrapping is added; numeric event/heartbeat/driver sensors themselves can perturb scheduling. New catchup timings are not a matched speed comparison against phase09 without these sensors.

OE preserves original concurrent sender-focus/receiver-sentinel ordering. FE prepares the receiver sentinel while offline and brings sender front before typing; this bundles focus and ordering. FE/IE differ only in second-browser ownership. Plain arms omit120new A editor admissions on purpose: they check A's600original positions arrive at B, B sentinel/new guard writing reaches A, Undo/Redo, full exports and locked offline reopen. They do not establish transport of120new A keystrokes; the six editor arms do. The raw generic guard label bothWay must be interpreted with that explicit coverage rather than promoted into identical functional coverage across targets.

The copied guard's target-B Undo comparison is made against target B's original text. Temporary control fields are removed before export. None of these changes edit or remove a repository test. Independent tests/fixtures and actual cumulative working test tree have distinct identity homes; working blobs are compared with patch09, frozen experiment corpus with phase09.

Keyboard event.timeStamp is assigned by the browser and is not a hardware input clock. The measured stamp→capture-handler interval is useful pipeline evidence, not a complete CPU attribution. Host/renderer clock brackets are retained; tiny negative intervals remain. Plain DOM mutation and nextRAF are not displayed pixels. EventTiming omits entries below the browser's minimum reporting threshold. Heartbeat intervals bound scheduling gaps and can include throttling/native/browser work. Temporal overlap with a slow input is not a causal explanation.

Node snapshots include numeric role basename/PID, timers and resource counters only, never process arguments/environment/content. No signal handler is added. Normal driver/worker exits provide snapshots; forcibly terminated child snapshots may be absent and are unavailable, not zero cost. Actual browser-root binary path/hash/version is attested using fresh disposable process metadata, improving the older executablePath-only scope; this does not attest every installed dependency.

No measurement/build/test-validator runs overlap. During long waits, source reads, small numeric progress summaries and preparation of analysis/documentation scripts continue. Complete fixed plan and all results remain, without stopping early for favorable timing. Original16ms guard misses and qualification obligations remain unchanged; this measurement study supplies no new adoption/production/physical-platform credit.
