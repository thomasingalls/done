# Phase 309 lab protocol — declared before measurement

No app/service implementation, profiles, databases or built assets enter the patch. Lab runs earn no credit. Frozen phase308 root remains read-only. No hardening, qualification, publication or deployment.

## Order and stop rules

0. One unchanged full Vitest run after the operator confirms a quiet host. Python records the actual child exit separately from the wrapper. Every timed run has an external 5-second aggregate CPU and executable-name-only top-process log. Preserve failures and residual load; no concurrent build, benchmark or agent work.
1. Instrument the unchanged maintenance algorithm in an isolated copy, G=1/R=1/V=0/D=0, range4/native8, quiet750ms. Run grown normal and withheld contention once each, then idle grown profiles once with polls and once with only idle polls suppressed (I). Do not suppress audits, hints, queued writes or lifecycle guards. Maintain 120-second completion wait, original >=60-key overlap predicate for typing journeys, original outer deadlines and all security checks.

Trace attempt start/end/furthest stage; journal entries/pending/hits/completed misses and lookup misses; replay duration and first lookup miss; durable delta count/bytes/chunks and caps; exact interruption booleans and originating queue job. Do not log writing, keys, credential material or authenticated payloads.

Discriminating predictions: queue priority interruptions attributable to idle polls recur on their scheduling rhythm; later saved attempts complete roughly one new miss; suppressing idle polls stops interruptions but does not by itself finish verification. If any prediction is contradicted, stop after this trace screen and report before building S/Y. A warm-audit job also enters the same run() queue; its presence must be tagged rather than mistaken for a poll. Warm audit interval is five minutes or 256 appended rows, so static code alone does not establish it occurs during these cases.

Any actual no-F cold-reopen failure stops immediately. A timeout before reaching cold is not a cold pass or a cold failure. Other failed declared cases remain visible and later declared work runs unless the operator's explicit stop applies.

## Measurement interpretation

Independent journeys are experimental units, not individual keys/positions. Repeated keys and stage events within a journey are dependent. Fixed small screens are descriptive; no significance, equivalence or physical-phone claim. All timed app runs use pinned Chrome, actual fictional profile copies, 1 CPU/1 GiB service, 16/s session and 64/s process budgets. Source, asset, fixture and apparatus identities are frozen before cells; any repair gets a new identity and retained failed/preflight record. No fake clock or civil-date bypass.

Landing requirements are reported separately after evidence; no hardening is authorized by this protocol.
