The generation test intentionally writes a fixture-authenticated marker outside the real exclusive
transition owner, to exercise the independent transaction fence. It does not implement rotation or
certify successor re-reservation. The Yjs case calls the byte carrier and reconstructs a test document;
it does not claim that the production editor or transport now obeys receive-before-promotion.

## Mutation controls

Each mutation uses its own frozen copy and runs its named scenario. It is detected only if the unmodified
case passes and the named assertion fails; unrelated execution errors cannot count as detections.

| Mutation | Discriminating assertion |
| --- | --- |
| Return success before transaction completion | No encryption after an aborted reservation |
| Skip durable reservation | Abandoned native encryption remains counted |
| Omit committing-generation fence | Changed generation refuses commit |
| Swallow record authentication failure | Bad tag refuses whole load |
| Permit equality at the invocation ceiling | Ceiling refuses before encryption |

Development run 01 passed all unmodified cases but found two harness defects: a mutation anchor had
drifted, and an already detected missing reservation continued into an unrelated retry failure.
Both were repaired before final evidence. Development run 02 and the final run detect every mutation.
The earlier development outputs remain ignored and are not this checkpoint's evidence.
