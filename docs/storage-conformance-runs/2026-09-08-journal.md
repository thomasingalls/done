## Mutation controls

Each mutant has its own frozen source copy. Detection requires its named assertion to fail while the
unmodified case passes; unrelated execution errors do not count.

| Mutation | Discriminating assertion |
| --- | --- |
| Skip localStorage append | Receipt already has a carrier |
| Acknowledge a refused write | Unavailable storage does not acknowledge |
| Remove a changed entry | Changed entry remains |
| Clean journal before content commit | Aborted flush retains journal |
| Reread journal after content | Handoff cannot fall between reads |
| Skip WASM disposal | Close erases the instance memory |

writer and later-chunk interruption, unavailable cold-read and foreign-namespace checks. Earlier fixture
